# API Key 与笔记目录设置设计

## 背景

应用目前从项目根目录的 `.env` 读取 DashScope API Key，并把笔记写入固定的默认目录。普通用户需要编辑配置文件才能启动转写，也无法在界面中更改笔记保存位置。

本次改动在主界面增加设置弹窗，只配置 API Key 和笔记保存文件夹。BASEURL、模型和工作空间配置不进入界面。

## 目标

- 主界面提供清晰的设置入口与模态弹窗。
- 用户可保存、替换或清除 API Key。
- 用户可通过系统文件夹选择器设置笔记保存位置。
- API Key 不以明文落盘，也不回传给渲染进程。
- 设置在应用重启后仍然有效。
- 未设置界面配置时，继续兼容现有 `.env` API Key 和默认笔记目录。

## 非目标

- 不配置 BASEURL、模型或 DashScope 工作空间 ID。
- 不迁移已经生成的笔记。
- 不在转写运行期间切换当前会话的连接信息或文件位置。
- 不实现多套配置、云同步或账户系统。

## 设计

### 1. 主进程设置存储

新增独立设置存储模块，数据文件位于 Electron `app.getPath('userData')` 下。笔记目录作为普通字符串保存；API Key 使用 Electron `safeStorage` 加密后以 Base64 字符串保存。设置文件采用版本化 JSON 结构，并通过临时文件后重命名的方式写入，避免中途写坏原文件。

读取异常、JSON 损坏或当前系统无法解密时，不向渲染进程暴露内部数据；该项被视为未配置并返回可理解的错误状态。完整 API Key 始终只存在于主进程。

### 2. IPC 边界

preload 暴露三个窄接口：读取公开设置状态、保存设置、打开系统目录选择器。公开状态只包含 `hasApiKey`、当前与默认笔记目录以及是否使用默认目录，不包含密钥内容。

保存请求采用显式 API Key 操作：`keep`、`replace` 或 `clear`。这样空输入不会意外覆盖已保存密钥。目录选择由主进程调用 Electron `dialog.showOpenDialog`，只允许选择文件夹。

运行中的转写不允许保存设置，避免界面显示的新配置与当前会话实际配置不一致。设置按钮在连接、转写、重连和停止阶段禁用。

### 3. 运行时配置优先级

启动新会话时，主进程即时读取设置：

1. API Key：已保存且可解密的设置值；否则使用 `DASHSCOPE_API_KEY`。
2. 笔记目录：已保存目录；否则使用应用现有默认目录。

现有 `.env` 中的 BASEURL、工作空间和模型配置保持不变。`TranscriptionSession` 接收解析后的输出目录并传给 `NoteWriter`。

### 4. 设置弹窗交互

主界面标题区域增加齿轮按钮。点击后加载公开设置状态并打开模态弹窗：

- API Key 使用密码输入框。已有密钥时输入框为空，并显示“已安全保存”；不输入表示保留原密钥。
- 输入新值时保存为替换操作。
- “清除已保存密钥”使用独立操作，清除后应用可继续回退到 `.env`。
- 笔记目录显示完整路径，旁边提供“选择文件夹”和“恢复默认”操作。
- 保存成功后关闭弹窗并显示短暂成功提示；保存失败时弹窗保持打开并展示错误。
- 点击取消、遮罩或按 Escape 关闭，不保存改动。

弹窗具有可访问的标题、标签、焦点样式和 `aria-modal` 语义。打开时聚焦首个可编辑控件，关闭后焦点返回设置按钮。

### 5. 校验与错误处理

- 新 API Key 会去除首尾空白，空值不能作为替换值保存。
- 选择的笔记目录必须是已存在的目录；无写权限或写入失败时沿用现有写笔记错误提示。
- 用户取消目录选择时不更改表单。
- 设置 JSON 写入失败或加密失败时不覆盖内存中的旧设置。
- 如果没有设置密钥且 `.env` 也无有效密钥，启动错误改为提示用户打开设置填写 API Key。

## 测试与验证

- 设置存储单元测试：默认值、路径保存、密钥加密落盘、读取解密、保留、替换、清除、损坏配置回退。
- 配置解析测试：界面设置优先于 `.env`，未设置时正确回退。
- IPC/契约测试：渲染进程读取结果不包含完整 API Key，目录选择只返回文件夹路径。
- 转写会话测试：选定目录被传给 `NoteWriter`，新笔记写入该目录。
- UI 手动验证：打开/取消/保存弹窗、密码可见性、目录选择、恢复默认、键盘 Escape、运行时禁用。
- 运行 `npm test`、`npm run typecheck` 和 `npm run build`。

## 验收标准

- 无需编辑 `.env`，用户可在主界面配置 API Key 并在重启后继续使用。
- 磁盘配置和渲染页面均看不到 API Key 明文。
- 用户选择的文件夹成为后续新笔记的保存位置。
- 清除自定义目录后恢复现有默认保存行为。
- 现有 `.env` 用户无需迁移即可继续使用。
- 自动测试、类型检查和生产构建通过。
