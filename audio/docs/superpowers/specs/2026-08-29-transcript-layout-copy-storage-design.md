# 实时原文布局、复制与日期目录设计

## 背景

当前实时原文段落被 CSS 限制为最大 `720px`，因此窗口较宽时卡片右侧会出现大片空白。最终确认的转写内容会立即写入项目的 `notes/` 目录，但没有按日期分组；界面也没有一次复制全部正文的入口。

本次改动采用已确认的方案 A：正文铺满可用宽度，渲染进程维护最终确认段落，通过 Electron 主进程写入系统剪贴板。

## 目标

- 最终确认的正文使用实时原文卡片的全部可用宽度，不再受 `720px` 上限限制。
- 在文档栏中提供“一键复制全部”按钮。
- 复制内容只包含最终确认的正文段落，段落间用一个空行分隔。
- 临时字幕、课程标题、开始时间、识别模型和 Markdown 分隔线不进入剪贴板。
- 默认把新笔记保存到项目 `doc/YY/M/D/` 目录，例如 `doc/26/8/29/`。
- 保留现有带完整日期、时间和课程标题的 Markdown 文件名，继续避免同秒同名文件被覆盖。

## 非目标

- 不保存或复制尚未最终确认的临时字幕。
- 不迁移现有 `notes/` 文件。
- 不增加富文本、HTML 或带项目符号的剪贴板格式。
- 不改变 Qwen 实时识别、音频采集或 Markdown 正文格式。

## 设计

### 1. 响应式正文布局

移除 `.final-transcript p` 和 `.partial-transcript` 的 `max-width: 720px` 限制，使两类文本都占据转写卡片扣除内边距后的可用宽度。保留现有字号、行高、段落间距和左侧圆点，以免扩大本次视觉改动范围。超长、不可断开的内容允许换行，避免横向溢出。

### 2. 最终段落状态

渲染进程新增最终段落字符串数组。收到 `final` 事件时，先规范化正文，再同时执行三件事：

1. 将段落追加到数组；
2. 将段落渲染到实时原文区域；
3. 更新段落计数和复制按钮状态。

开始新会话时清空数组，并将复制按钮恢复为禁用。停止转写后数组继续保留，使用户仍可复制本次会话内容。

纯函数 `buildTranscriptText` 负责过滤空段落、修剪首尾空白，并用 `\n\n` 连接段落。复制逻辑不读取 DOM，避免界面结构变化影响复制结果。

### 3. 复制交互与进程边界

“复制全部”按钮放在文档栏右侧，与段落计数并列。没有最终段落时按钮禁用；有内容后启用。

点击按钮后，渲染进程调用 preload 暴露的窄接口，将 `buildTranscriptText` 的结果传给主进程。主进程使用 Electron `clipboard.writeText` 写入系统剪贴板。这样保持 `contextIsolation` 边界，并避免依赖浏览器 Clipboard API 的安全上下文和权限行为。

复制成功后，按钮文字短暂变为“已复制”，随后恢复为“复制全部”。连续点击时重置恢复计时。复制失败时沿用现有消息框显示用户可理解的错误，并保持段落数据不变。

### 4. 日期分组保存

默认基础目录由 `notes/` 改为项目当前工作目录下的 `doc/`。`NoteWriter.create()` 使用会话开始时间创建三级子目录：

```text
doc/<两位年份>/<不补零月份>/<不补零日期>/
```

例如 2026 年 8 月 29 日生成：

```text
doc/26/8/29/2026-08-29_09-00-08_TypeScript 网课.md
```

目录递归创建。文件名、标题清理、同名递增后缀及正文追加规则保持不变。`.gitignore` 忽略新的 `doc/` 输出目录。

## 数据流

```text
Qwen final 事件
  -> 规范化最终正文
  -> 最终段落数组
     -> 页面段落渲染与计数
     -> buildTranscriptText
        -> preload IPC
           -> Electron 主进程 clipboard.writeText

会话开始时间
  -> NoteWriter
  -> doc/YY/M/D/
  -> Markdown 文件
```

## 错误处理

- 空段落不会加入数组，也不会写入剪贴板。
- 无最终段落时复制按钮禁用，主进程不会收到空复制请求。
- 主进程拒绝非字符串或空白字符串，防止错误调用覆盖用户剪贴板。
- 复制异常通过现有错误消息区域反馈，不中断转写或文件写入。
- 日期目录创建或 Markdown 写入失败时，继续沿用当前会话的致命写入错误处理。

## 测试与验证

- `NoteWriter` 测试验证 2026-08-29 的输出位于 `doc/26/8/29/` 对应目录，并继续验证同名文件不覆盖。
- `buildTranscriptText` 单元测试验证段落过滤、首尾修剪、空行连接以及全空输入。
- 复制 IPC 边界测试验证只接受非空字符串，并调用 Electron 剪贴板一次。
- UI 状态测试验证无段落时禁用、收到最终段落后启用、新会话重置，以及复制成功反馈恢复。
- 运行完整测试、TypeScript 类型检查和生产构建。
- 手动在宽窗口验证正文占满卡片可用宽度、无横向滚动，并验证 Finder 中的新路径。

## 验收标准

- 宽屏下正文不再固定停在约 `720px` 处，截图标记区域被正文自然利用。
- “复制全部”只复制最终确认的正文，结果按段落保留空行。
- 复制按钮的禁用、成功和失败状态清晰，不影响正在进行的转写。
- 新文件默认生成在 `doc/YY/M/D/`，现有 `notes/` 文件保持原位。
- 自动测试、类型检查和构建全部通过。
